# 🌍 De Pátria para Pátria

Um site desenvolvido para ser **responsivo e adaptável** a diferentes tamanhos de tela — desde computadores até dispositivos móveis.  
O projeto apresenta uma estrutura organizada e moderna, com foco em boas práticas de HTML, CSS e versionamento com Git/GitHub.

---

## 🧩 Tecnologias utilizadas

- **HTML5** → estrutura semântica e acessível  
- **CSS3** → estilização responsiva e uso de media queries  
- **@font-face** → integração de fontes locais personalizadas  
- **Git & GitHub** → controle de versão e hospedagem do código  
- **Normalize.css** → padronização de estilos entre navegadores  
- **EditorConfig** → consistência de formatação entre diferentes editores  
- **Prettier** → formatação automática do código

---

## 📱 Responsividade

O layout foi projetado para se ajustar automaticamente a:
- Monitores grandes (desktop)
- Tablets
- Smartphones

As **media queries** garantem que o conteúdo mantenha legibilidade e proporção em qualquer resolução.
